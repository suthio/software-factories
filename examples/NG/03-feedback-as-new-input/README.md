# NG：別セッションで同じ成果物の修正を頼む

**場面：** できた脱出ゲームで遊んでみたら、出口の手がかりが分かりにくい。そこで別セッションを開き、「候補2の受付に、裏口のヒントを足して」と頼んでから発表しました。

**なぜNG？** 別セッションでも、遊んだ人が直す場所を決めて、同じ候補を直させています。できたゲームで遊んでみること自体はOKです。

**OKにするなら：** 「手がかりを読めば、次に移動する部屋を推測できるか」のように、別のマップにも使えるレビューの条件をファクトリーに足します。そのうえで最初から生成するなら、同じ水族館の題材でも構いません。舞台を図書館に変えて試すと、ほかのマップにも同じ条件が使えるか分かります。前にできたものを、ファイル形式などの参考に渡すのもOKです。
