# NG：できあがったものを仕様として渡す

**場面：** 完成済みの `total.py` を長い「仕様」として貼り付け、「そのままファイルに出力して」とAIに頼みました。脱出ゲームでいえば、すべての部屋・文章・移動先を人が完成させておき、AIにはJSONへの変換だけをさせるケースです。

**なぜNG？** ゲームの中身はすでに人が作っていて、AIは形式を変えるだけだからです。雰囲気を伝える参考画像や、作ったマップで遊ぶための `play.py` は先に用意しても構いません。

**OKにするなら：** 「閉館後の水族館が舞台。脱出には鍵が必要で、最短でも4手かかる」と伝えます。部屋や手がかりはAIに作らせて、条件どおりに脱出できるかテストします（[脱出ゲームの作例](../../OK/02-escape-room/)）。
