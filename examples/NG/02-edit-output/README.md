# NG：発表前に成果物を手直しする

**場面：** 生成したCLIが、合計のあとに余計な説明を出しました。発表前に `total.py` を開き、その説明を出す1行だけ消しました。脱出ゲームなら、別々の候補から気に入った部屋を取って、1つのマップに組み合わせるのも同じです。

**なぜNG？** 発表するものに人の編集が入っているからです。生成したままの候補から1つを選んで遊んだり、発表スライドに感想を書いたりするのはOKです。

**OKにするなら：** [できた候補をそのまま選ぶ](../../OK/03-select-outputs/)か、失敗した版をそのまま見せます。「合計だけを出すテストを書いておけば、余計な説明を弾けた」という話も発表の題材になります。
