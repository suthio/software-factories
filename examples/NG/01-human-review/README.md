# NG：途中で人が合否を決める

**場面：** AIが金額を合計するCLIを作りました。人が動かしてみて「負数を受け付けてしまう」とAIに伝え、修正後に人が「これでOK」と判断して終了しました。

**なぜNG？** コードはAIが書いても、直す箇所と合格の判断は人が決めています。自動テストがあっても、人が毎回「続行」や「採用」を押さないと進まないなら同じです。ログを見るだけならOKです。

**OKにするなら：** 実行前に「負数を渡したら終了コードは `2`」というテストを書きます。落ちたらスクリプトがテスト結果をAIに渡します。合格するか、決めた回数に達したら止めます（[テストで自動修正する作例](../../OK/01-auto-retry/)）。
