# OK：テストの失敗をAIに返して自動修正する

AIに、コマンドラインで渡した金額を足すプログラムを書かせます。たとえば負数を受け付けてしまったら、そのテストの結果をAIに渡して直させます。人が途中で「ここを直して」と頼む必要はありません。

1. AIが `total.py` を作る。
2. スクリプトが、合計値やエラー時の動作を検査する。
3. テストに落ちたら、その結果を新しいAIセッションに渡す。AIは同じファイルを直す。最初の生成を含めて最大3回まで。

## 動かす

必要なのは Python 3 と、認証済みの Codex CLI です。検査ではAIが生成したコードをその場で実行するため、検証用の認証情報だけを置いた隔離環境で試してください。

リポジトリのルートで次を実行します。

```sh
python3 examples/OK/factory.py examples/OK/01-auto-retry
```

生成された `total.py` は、冒頭の `出力先:` に表示されたディレクトリにあります。合格したら `python3 "出力先のパス/total.py" 120 80 50` で試せます。出力は `250` です。

ファクトリーの終了コードは、テスト合格なら `0`、3回試しても合格しなければ `1`、Codexや検査スクリプトに異常が起きたら `2` です。

## 自分の題材に置き換える

`spec.md` に作りたいものを書き、`check.py` にテストを書きます。この例では合計が合っているかに加えて、引数がないときや、負数・小数・文字列を渡したときの終了コードと標準出力を見ています。テストに書いていない動作は判定しません。
