# 脱出ゲームの共通仕様

与えられた題材の舞台から、内部を探索して鍵を見つけ、出口から外へ脱出する短いゲームのシナリオを作ってください。成果物は作業ディレクトリの `game.json` のみとし、UTF-8で64 KiB以下、プレイヤー向けの文章は日本語で書いてください。

- トップレベルの項目は `title`（タイトル）、`start`（開始地点の部屋ID）、`goal`（出口の部屋ID）、`key_room`（鍵がある部屋ID）、`rooms`（部屋IDをキーにしたオブジェクト）。開始地点・出口・鍵のある部屋はそれぞれ別の部屋にする。
- 部屋は5〜9個。各部屋には `description`（情景や手がかりの文章）と `exits`（移動コマンドをキーにしたオブジェクト）を持たせる。出口の部屋では `exits` が空でもよい。
- 移動先は `{"to": "部屋ID", "requires_key": false}` の形にする。部屋IDと移動コマンドには半角の小文字英数字とハイフンを使い、先頭は英小文字にする。`quit` は移動コマンドに使わない。選択肢は1部屋につき最大4つ。
- `key_room` に入ると自動で鍵を拾う。`requires_key` が `true` の移動には鍵が必要。開始地点から出口へ到達でき、かつ鍵なしでは脱出できないようにする。最短の脱出経路でも4回以上の移動を必要とする。
- 情景を読むと行き先を推測できるようにする。鍵の部屋や出口が分かりにくい場合は、別の部屋に手がかりを置く。
