# OK：企画メモから短編動画を作る

「AIに動画を作らせると、なぜ同じ字幕ミスを繰り返すのか？」という短編を作ります。[企画メモ](brief.md)を渡すと、ナレーションと字幕付きのMP4ができます。`report.json` には、検査に落ちた理由とやり直した工程が残ります。実行には別リポジトリの `addinginc/yt` が必要です。

## 字幕や音声に問題があったら、該当する工程をやり直す

| 不具合 | 検出する役 | 直す役 |
| --- | --- | --- |
| 「動画を作るときには、」だけが一枚の字幕に出る | 字幕検査。短い前置きだけの発話を弾く | 台本役。改行を足さず、一息で意味が通る言い方にする |
| 完成MP4で字幕が一瞬消える、または別の字幕が出る | 完成動画の全フレームを、台本から作った字幕画像と照らし合わせる | 映像役。字幕の描画と合成をやり直す |
| 指定した読みが合成設定に入っていない、または読み上げで単語が抜ける | 辞書の読みが合成用の音素に入っているか調べる。完成した音声も台本なしで文字起こしし、結果を台本と比べる | 音声役。指摘された発話をもとに、音声を作り直す |
| 台詞の間が空きすぎる | WAVと完成MP4で無音の長さを測る | 音声役 |
| 最後の画面とナレーションの説明が合わない | 任意の完成版レビュー。該当する時刻の映像と音声を見る | 映像役。台本と音声はそのまま使う |

「字幕が枠からはみ出す」と指摘されたら、次回から描画に使うフォントで文字の幅を測り、収まらない台詞を台本役に返します。指摘をプロンプトに書き足すだけでなく、同じミスを見つけたら止めるテストにしておくのがこの例の工夫です。「画面の見出しが説明に合っているか」まで見たいなら、別途レビュー役をつなぎます。

## 動かす

ファクトリーのコードは `addinginc/yt` にあります。このリポジトリだけではMP4を作れません。実行するには `addinginc/yt` へのアクセス、Python 3.11以上、ローカルのCOEIROINK、FFmpeg、ImageMagick、日本語フォントが必要です。

`addinginc/yt` のルートで次を実行します。`brief` には、このディレクトリの `brief.md` の絶対パスを指定してください。

```sh
brief=/path/to/software-factories/examples/OK/06-video-factory/brief.md
work=$(mktemp -d)
model=/path/to/local/whisper-model
python3 tools/video-factory/factory.py "$brief" "$work/demo" --whisper-model "$model"
```

デモでは、わざと短い前置きだけの字幕が入った台本を使います。検査に落ちると修正版に切り替わり、その台本から音声と映像を作って合成します。

文字起こしには `mlx_whisper` とローカルモデルが必要です。文字起こし以外の工程を試すなら、`--whisper-model` の代わりに `--skip-transcription` を指定します。文字起こしでは、たとえば「にほんばし」と「にっぽんばし」が同じ「日本橋」になることがあります。実際の発音やイントネーションまで見るには、音声を聞けるレビュー役が必要です。

発表では、先に完成動画を流し、そのあと最初に落ちた字幕と直したあとの台本を見せると違いが伝わります。この作例では動画を公開・投稿しません。
