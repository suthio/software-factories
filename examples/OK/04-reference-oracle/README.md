# OK：別のコードでテストの正解を出す

CSVを読み、請求明細の合計を出す `invoice.py` をAIに作らせます。[金額を足すCLIの作例](../01-auto-retry/)では、人がテストの入力と正解を書いています。ここでは検査スクリプトが明細を作り、別のコードで合計を計算します。

```sh
python3 examples/OK/factory.py examples/OK/04-reference-oracle
printf 'price,quantity\n120,2\n80,1\n' | python3 '出力先のパス/invoice.py'
```

1. 生成役は仕様を読み、CSVを扱うCLIを作ります。検査側のコードは生成物に含めません。
2. 検査スクリプトは、金額や数量が0の明細、空の明細、乱数で作った16通りの明細を試します。不正なCSVも渡し、仕様どおりの終了コードと標準出力になるか調べます。
3. 結果が食い違ったら、最初に失敗した入力と期待値をAIに渡します。

たとえば単価3円、数量4の明細なら、正解は12円です。数量を掛け忘れたプログラムは3円を返すので、テストに落ちます。乱数のシードは固定してあるので、実行し直しても同じ明細で試せます。
