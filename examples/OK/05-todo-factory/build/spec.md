# 実装エージェント：TODOウェブアプリの受け入れ仕様

今回の入力にある題材と、計画があればその計画を参考に、Python標準ライブラリだけで動くウェブアプリ `app.py` を作ってください。他のファイルに依存しない1ファイルの成果物にします。この基本仕様は変更しません。不合格なら検査結果を読んで同じ `app.py` を修正し、検査側は変更しません。外部ネットワークに接続しません。

## 起動

- `python3 app.py --port 8000 --data todos.json` で `127.0.0.1` にだけ起動します。
- `--port 0` は空きポートに割り当てます。任意の `--ready-file PATH` があれば、サーバーをバインドした後、実際のポート番号をASCIIの10進数でそのファイルに書きます。
- `--data` のファイルに保存し、再起動しても明細と完了状態が残ること。削除した明細は復活しません。

## ブラウザ画面と操作

- `GET /` はUTF-8のHTMLのTODO一覧。追加フォームは `method="post" action="/tasks"`、項目名は `title`。JavaScriptなしで操作できます。
- 一覧にはTODOを `li` で出し、各項目に正の整数の `data-task-id` と `data-done="true"` または `data-done="false"` を付けます。タイトルはHTMLとして解釈されないように出力します。
- `POST /tasks` はURLエンコードされた `title` を追加し、初期状態は未完了。空白だけなら、データを変更せずHTTP 400を返します。
- 各TODOに `method="post"` の切り替えと削除のフォームを置きます。`POST /tasks/{id}/toggle` は完了と未完了を切り替え、`POST /tasks/{id}/delete` は削除します。
- 更新に成功したら、いずれの操作もHTTP 303と `Location: /` を返します。
