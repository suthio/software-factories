# 計画エージェント：TODOアプリの作業計画

今回の入力を読み、標準ライブラリで作るローカルTODOウェブアプリの計画を `plan.json` に書いてください。実装やテストは書きません。成果物はUTF-8で16 KiB以下です。

JSONは `workflow`、`storage`、`interface` の3キーだけを持ち、値は短い日本語の文字列です。

- `workflow`：追加、完了切り替え、削除をどんな順で作るか。
- `storage`：ローカルファイルに保存し、再起動後も復元する方法。
- `interface`：HTMLフォームを備えた1ページで、入力・完了状態・削除をどう見せるか。

不明点は題材の範囲で決め、人には確認を求めません。ネットワークへの公開、アカウント、外部DBは計画に含めません。
