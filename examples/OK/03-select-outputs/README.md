# OK：候補を3つ作って、手を加えずに1つ選ぶ

同じ水族館の仕様から脱出ゲームを3つ作ります。生成と検査がすべて終わったら、手を加えずに発表する1つを選べます。

候補は1つずつ作ります。AIセッションと作業フォルダは候補ごとに分け、ほかの候補はAIに見せません。どの候補も[水族館の脱出ゲーム](../02-escape-room/)と同じテストにかけ、1候補につき最大3回試します。

## 生成して比べる

```sh
python3 examples/OK/03-select-outputs/factory.py
```

実行が終わると、出力先に `candidates.json` が残ります。各候補の `status` は `passed`（合格）、`rejected`（最大3回の試行でも不合格）、`error`（生成や検査の異常終了）のいずれかです。途中で `error` になった場合は後続の候補を作らずに停止し、その時点までの記録を `candidates.json` に残します。`candidate-1.log` などで、それぞれの検査経過も確認できます。

合格した `candidate-1/game.json` などを [02のプレイヤー](../02-escape-room/) で遊び、発表する1つを手を加えずに選びます。候補どうしの部屋を組み合わせたり、「この部屋だけ直して」と追加で生成させたりはしません。

候補を順に作るので、AIを最大9回呼び出します。時間がなければ、先に[水族館の脱出ゲーム](../02-escape-room/)を1つ作ってみてください。3つできたら、鍵の置き場所や部屋のつながりを見比べてみましょう。
